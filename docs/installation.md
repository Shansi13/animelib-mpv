# Installation guide

See the main [README](../README.md) for the complete setup.

Quick checklist:

- [ ] Install mpv.
- [ ] Create `C:\mpv-launcher`.
- [ ] Copy `install/launch-mpv.ps1` into that folder.
- [ ] Import `install/mpv-protocol.reg`.
- [ ] Install Tampermonkey.
- [ ] Add `userscript/AnimeLib-to-mpv.user.js`.
- [ ] Open an AnimeLib episode and click **Открыть в mpv**.
